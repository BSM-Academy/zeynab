Ta clé Kie

Ta clé Kie

Kie, c'est là que je fabrique les images de ta page. Une page complète consomme environ 150 à 250 crédits : je t'annonce toujours le nombre avant de lancer.

Ouvre une note vide sur ton ordinateur : tu y colleras ta clé le temps de l'installation, puis tu la supprimeras.
  1. Crée ton compte Kie si on te le demande, puis ajoute des crédits dans Billing.
  2. Dans API Keys, clique sur Create New Key (repère 1), nomme-la Zeynab et valide.
  3. Clique sur le bouton copier à droite de ta clé (repère 2) et colle-la dans ta note.

Le démarrage et les réglages

Fais défiler la fenêtre vers le bas :

1. Dans « Script de configuration », colle :

#!/bin/bash
pip install -q pillow 2>/dev/null || true

2. Dans « Variables d'environnement », colle :

KIE_API_KEY=cloud

3. Clique sur Ajouter un environnement en bas (ou Enregistrer les modifications).

Le coffre

Range ta clé Kie

Le coffre (« Secrets réseau ») garde ta clé à l'abri : je peux m'en servir, mais jamais la lire.

Rouvre ton environnement (bouton nuage → Cloud → passe la souris sur Zeynab → roue dentée), puis clique sur Ajouter un secret :

  1. Nom : Kie
  2. Sites web autorisés : tape api.kie.ai puis appuie sur Entrée.
  3. Valeur : colle ta clé Kie (laisse Authorization et Bearer tels quels).
  4. Clique sur Ajouter, puis sur Enregistrer les modifications.

Ta clé est à l'abri : tu peux supprimer ta note.

Un souci ?

Je dis que la clé Kie est « MANQUANTE »

Revois l'écran « Le démarrage et les réglages » de mon atelier, puis démarre une nouvelle session.

Je ne vois pas ta boutique ou Moonbundle

Revois les écrans « Connecte ta boutique » et « Connecte Moonbundle », puis démarre une nouvelle session.

Erreur 401 ou « invalid api key » (Kie)

La clé est fausse : supprime le secret Kie dans le coffre et ajoute-le à nouveau.

Plus de crédits Kie

Recharge ton compte dans Kie → Billing.

L'offre de packs n'apparaît pas

Dans Moonbundle, vérifie que la démo (ou un forfait) est active. Je m'occupe du reste dans ta copie de thème.
